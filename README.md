# Naxas License Portal
Secure Laravel portal for manual Buildora CMS Single Site licensing. Phase 0–1 supports request creation, administrator review/manual licenses, RS256 signing, proof-bound status retrieval, a buyer review page, audit evidence, and minimal health reporting. It intentionally excludes billing, marketplaces, subscriptions and updates.

See `documentation/local-development.md`, `documentation/buildora-local-integration.md`, and the security/signing documents.
