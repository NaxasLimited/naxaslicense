# Buildora local integration
1. Start this portal after migration/seed and admin creation.
2. Configure Buildora CMS's license portal base URL to this portal.
3. Enable its portal integration locally.
4. In Buildora, Generate Activation Request.
5. Sign in here and confirm it under Activation Requests.
6. Create a customer and matching Single Site license.
7. Open the request, select the license, and approve.
8. Return to Buildora CMS.
9. Check activation status using the displayed one-time request proof.
10. Confirm Buildora accepts the RS256 token and reports the license active.

Use a production-shaped host rather than localhost when testing production capacity. Full cross-repository acceptance remains pending until the Buildora verifier repository/fixture is available.
